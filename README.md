📥 Installation

1. Clone Repository

git clone https://github.com/7383739393837636363/Enyo-Stfu.git

2. Enter Project Directory

cd Enyo-Stfu

3. Install Dependencies

npm install

4. Configure the Bot

Set up the project's configuration file according to your environment.

Add the required account/session information and administrator settings where supported.

5. Start the Bot

Use the start script configured in "package.json".
